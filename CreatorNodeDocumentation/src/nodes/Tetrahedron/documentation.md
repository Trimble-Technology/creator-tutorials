# Tetrahedron

**_Creates a tetrahedron mesh at vector positions._**

---

> #### DEPRECATED
>
> Primitives in this node are incorrectly sized and not positioned at world origin.
>
> Superseded by [Tetrahedron](/nodes/TetrahedronV2/documentation.md)


#### Inputs

* _center_

  * The vector value that defines the center of the output tetrahedron.

* _scale_

  * The vector value that defines the scale of the output tetrahedron.

* _weld vertices_

  * Sets whether to weld the vertices of the output tetrahedron or not.


#### Outputs

* **_geometry_**

  * Output primitives.

* _points_

  * The list of points of the output primitives.

* _points.x_

  * The list of x values of the points of the output primitives.

* _points.y_

  * The list of y values of the points of the output primitives.

* _points.z_

  * The list of z values of the points of the output primitives.
